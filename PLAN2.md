# План разработки: Quick Web-Search Launcher для Noctalia Shell

## 1. Архитектура и структура проекта
Плагин расширяет стандартный лаунчер Noctalia, регистрируясь как `launcher provider`.

**Структура папки:**
└── web-search-launcher/
    ├── plugin.toml   # Манифест плагина с указанием типа провайдера
    └── init.luau     # Перехват ввода, генерация вариантов и запуск браузера

## 2. Механика префиксов
* Плагин должен реагировать только на ввод, начинающийся со специальных триггеров:
  * `:g ` — Поиск в Google
  * `:y ` — Поиск в YouTube
  * `:gh ` — Поиск на GitHub
* Если префикса нет, плагин возвращает пустой список вариантов, не мешая штатному поиску приложений.

## 3. Интеграция с UI Лаунчера
* При совпадении префикса плагин динамически формирует один или несколько пунктов меню (matches).
* Текст пункта: `"Искать в Google: [запрос пользователя]"`.
* Иконка: Соответствующая иконка поисковика (используя Nerd Fonts или системные иконки).

## 4. Обработка действия (Action)
* При нажатии `Enter` на сгенерированном пункте, плагин перехватывает событие активации.
* Извлекает поисковый запрос, кодирует его (URL-encode, заменяя пробелы на `%20` или `+`).
* Формирует финальную ссылку: `https://google.com...`
* Выполняет системную команду открытия ссылки через браузер по умолчанию (например, `xdg-open <URL>`).
* Закрывает окно лаунчера.
