# План разработки: Workspace Clean-Up Assistant для Noctalia Shell (Niri)

## 1. Архитектура и структура проекта
Плагин создается как фоновый сервис (headless background service) на Luau в Noctalia v5+. Его цель — не вмешиваться в работу принудительно, а лишь напоминать о забытых ресурсах.

**Структура папки:**
└── workspace-cleaner/
    ├── plugin.toml   # Манифест плагина
    └── init.luau     # Логика мониторинга окон и отправки напоминаний

## 2. Сбор данных и API
* **Триггер:** Периодический таймер (раз в 1-5 минут).
* **Получение состояния Niri:** Вызов команды `niri msg -j outputs` для получения текущего JSON-дерева окон.
* **Анализ:** Поиск неактивных окон с целевыми заголовками/классами (например, пустые терминалы, неактивные вкладки).

## 3. Алгоритм отслеживания простоя
* Хранить в памяти Luau-таблицу (словарь):
  * Ключ: ID окна (`window_id`).
  * Значение: Временная метка (timestamp), когда окно потеряло фокус.
* Если окно в фокусе -> удалять его из таблицы (сбрасывать счетчик).
* Если окно не в фокусе и подходит под критерии:
  * Если его нет в таблице -> записать текущее время.
  * Если оно уже есть -> проверить разницу во времени.

## 4. Мягкое уведомление (Action)
* Если окно простаивает дольше 20 минут, плагин вызывает встроенный Notification API Noctalia.
* Текст уведомления: *"Окно [Название] не используется уже более 20 минут. Возможно, его стоит закрыть?"*
* **Важно:** Плагин сам ничего не закрывает, оставляя контроль пользователю. После отправки уведомления таймер простоя для этого конкретного ID сбрасывается или помечается как "уведомлен", чтобы не спамить пользователя каждую минуту.
